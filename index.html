Thesis

LLMs: Establishing Confidence Bounds on Predictions

M.Tech thesis, IIT Madras, 2025 to 2027. Advised by Prof. Sri Vallabha Deevi.

Language models sound just as sure when they're wrong. I'm building a way to estimate how far each answer can be trusted using only the model's outputs, so it works with any model behind an API, without access to its weights.

Alongside this, I'm diagnosing where NLI-based methods go wrong and tracing each failure to a specific model behaviour.
